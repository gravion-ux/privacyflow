# Gravion brand conventions

The four project names are:

1. **Localshare**
2. **Privacyflow**
3. **Agent Browser**
4. **Gravion Trainner** (spelling retained exactly as specified)

Use the footer credit **“Built with graviondev”** only in Gravion-generated templates or where the site owner explicitly opts in. Localshare's tunnel must not rewrite arbitrary third-party HTML or inject branding into an existing website without consent.

A branded public hostname such as `*.graviondev.com` requires a registered domain, DNS control and TLS configuration. The brand string alone does not create a reachable domain.
